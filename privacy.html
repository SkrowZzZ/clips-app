Privacy policy

Last updated: November 2, 2026

Clips is a personal tool used only by its owner to upload and schedule videos to their own YouTube channels.

What it accesses

With the permission you grant through Google's sign-in, Clips uses the YouTube Data API to see the YouTube channel you choose, upload videos to it, set their title, description and publish time, and read back their status and view counts. It does not access any other Google data.

How the data is used and stored

The sign-in token and the video information are stored only on the owner's private server and are used only to upload and track videos on the owner's channels. Nothing is sold, shared with third parties or used for advertising.

Removing access

You can revoke Clips' access at any time at myaccount.google.com/permissions. The stored token stops working immediately, and it can be deleted from the server on request.

Google API Services

Clips' use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements, and the YouTube Terms of Service. See also the Google Privacy Policy.
